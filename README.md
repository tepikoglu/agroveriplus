# AgroVeri+
Digital Certification Verification Platform for Organic Agriculture

## What it does
Farmers upload organic certificates → AgroVeri+ generates SHA-256 hash + QR code → Consumers scan QR to verify authenticity

## Problem
Organic certification fraud costs hundreds of millions annually. Washington Post (2017) exposed fraudulent organic shipments through Turkish warehouses. EU revoked certification authority for Türkiye.

## Pilot Partner
ÇOFÜB (Çarşamba Organic Hazelnut Producers Union), Samsun, Türkiye

## Tech Stack
Web Crypto API (SHA-256) | IPFS | QR Code | FastAPI
